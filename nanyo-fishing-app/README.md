# 南予釣行ナビ

愛媛県、特に**南予**の海釣りに特化した釣行支援 Web アプリ（PWA）です。

> **「今日、どこへ行けば、何が、何時ごろ、どんなルアーで釣れそうか」**
> を初心者でも一目で判断できることを目標にしています。

スマートフォンでの現地利用を最優先に設計し、PC でも使えるレスポンシブ構成です。ログイン不要・APIキー不要で動作します。

---

## 主な機能

### 🏠 今日の南予・釣り予報（ホーム）
日付・現在時刻・天気・気温・降水確率・風向・風速・波・潮回り・満潮/干潮・日の出/日の入り・朝夕まづめ・**現在の釣れやすさ**を1画面に表示。
**本日のBEST TIME**（例: `18:10〜20:40 期待度 87点`）と**おすすめ釣り場 TOP5** を大きく出します。

### 📈 時合い予測エンジン（このアプリの中核）
潮の動き／満潮・干潮前後／潮止まり／朝夕まづめ／日の出入り／風速／風向／天気／気圧変化／波／季節／時間帯／魚種／釣り場 を組み合わせ、**0〜100点の期待度**を10分刻みで計算します。

| 表示 | 点数 |
|---|---|
| 🔥 爆釣期待 | 80〜100 |
| ◎ かなり期待 | 70〜79 |
| ○ 期待できる | 55〜69 |
| △ 普通 | 40〜54 |
| × 厳しい | 0〜39 |

配点は「条件100点 × 適性倍率 + 個人補正」の形です。

| 条件（合計100点） | 配点 |
|---|---|
| 潮（動き・満干からの時間） | 28 |
| 時間帯（まづめ・魚種の活性） | 26 |
| 風（風速・向かい風/追い風/横風） | 20 |
| 天気（天候・気圧変化） | 14 |
| 波 | 12 |

これに **適性倍率 0.55〜1.0**（季節10点＋釣り場×魚種の相性7点から算出）を掛け、さらに**個人の釣果傾向による補正 ±6点**を加えます。シーズン外の魚種は倍率で自動的に下がります。

安全上の危険がある時間帯は、期待度が高くても**25点で頭打ち**にし、警告表示を優先します。

### 📊 24時間の釣れやすさグラフ
0:00〜24:00 の期待度を折れ線で表示し、**満潮・干潮・日の出・日の入り・朝夕まづめ・現在時刻・BEST TIME 帯**を重ねます。

### 🐟 魚種別予測・ルアー提案
アジ／メバル／シーバス／チヌ／アオリイカ／青物／タチウオ／カサゴ／ハタ類／マダイ／ヒラメ／キス の12魚種。
それぞれシーズン・時間帯・適した潮・水深・適水温・ルアー（種類/サイズ/重量/カラー/レンジ/アクション）・タックル・エサ釣りの仕掛けを登録しています。

**場所 × 魚種 × 時間 × 潮 × 風**からおすすめルアーを1つに絞り、理由つきで提示します。

> 八幡浜港 / アジ / 19:30 / 上げ潮 / 風速2.5m/s
> → **ジグヘッド+ワーム** 0.6〜1.5g / 1.5〜2.5インチ / クリア・ケイムラ / 表層〜中層
> 理由: 夕まづめ。上げ潮で港内・岸寄りへの回遊が期待できる。風速2.5m/sと穏やかで軽いリグも扱える。

### 🗺️ 釣り場マップ
OpenStreetMap + Leaflet（APIキー不要）。**国土地理院「全国最新写真（シームレス）」**への切り替えも可能です（出典表示あり）。
マーカーはその日の期待度で色分け・点数表示。地域／魚種／初心者向きで絞り込めます。

各釣り場では、釣り場名・地域・ポイント種類・狙える魚・おすすめ時期・おすすめ時間・有利な潮・水深・ルアー・仕掛け・駐車場・トイレ・常夜灯・足場・初心者向きか・危険度・現在の釣れやすさ を確認できます。

### 🌊 潮汐
南予の主要7地点（長浜・八幡浜・三崎・三瓶・宇和島・御荘・愛南）の潮位グラフ・満潮/干潮時刻と潮位・潮回り・上げ潮/下げ潮/潮止まり・現在時刻ラインを表示します。

### 🚗 今から行くなら
GPS または拠点エリアを起点に、**移動時間・到着時刻・日没までの残り時間・到着後に残っている時合い**を考慮して「今から行くならおすすめ TOP3」を出します。

### 🏆 南予ランキング
地域別ランキングと、主要6エリア（長浜・八幡浜・佐田岬・三瓶・宇和島・愛南）× 5魚種（アジ・メバル・シーバス・アオリイカ・青物）のマトリクス比較。

### 🎣 釣果記録・釣果分析・自分専用AI予測
日付・時間・釣り場・魚種・サイズ・匹数・ルアー・カラー・重量・潮・天気・風・写真・コメントを記録。
月別/魚種別/釣り場別/潮回り別/時間帯別/ルアー別の集計に加え、**自分が釣れやすい条件**を自動で言語化します。

> **八幡浜港(みなっと周辺) が得意な釣り場です**
> 1回あたり平均 9.3 匹（4回の釣行）。主なターゲットは アジ。
> 好調だったときの条件は「夜(前半) / 上げ潮 / 大潮 / 風速 2.1m/s 以下 / ジグヘッド1.2g」でした。

分析結果は期待度にも ±6点の範囲で反映されます。いまはルールベース（統計）で、`lib/personal.ts` の `PersonalAnalyzer` を差し替えれば AI / 外部API 版に置き換えられる構造です。

### ⭐ お気に入り / 明日・週末・指定日の予測
お気に入り釣り場の今日の期待度を一覧表示。日付は「今日／明日／今週末／任意の日付」で切り替えられます。

### 🚨 安全機能
強風・突風・高波・雷・大雨・低気圧（台風）接近・熱中症・低温 を判定し、**釣果期待度より安全警告を優先**して表示します。磯・サーフ・危険度の高い釣り場には、より厳しいしきい値を適用します。立入禁止・私有地・漁業関係の注意もポイントごとに表示します。

## データの出所（重要）

**架空の値を実データとして表示しません。** 画面上のバッジで出所を必ず明示しています。

| バッジ | 意味 |
|---|---|
| `予測値` | 外部の公開データから取得した予報値 |
| `参考値` | アプリ内の計算による目安、またはオフライン時の前回取得値 |
| `データ未取得` | 取得できず、平年値から生成した参考値 |

| 項目 | 出所 |
|---|---|
| 天気・気温・降水確率・風・気圧 | [Open-Meteo](https://open-meteo.com/)（APIキー不要）→ `予測値` |
| 波高 | [Open-Meteo Marine](https://marine-api.open-meteo.com/)（APIキー不要）→ `予測値` |
| 日の出・日の入り・月齢 | アプリ内の天文計算（実用精度） |
| 潮位・満潮・干潮・潮回り | アプリ内の簡易調和計算（M2+S2分潮）→ **`参考値`** |
| 地図 | OpenStreetMap |
| 航空写真 | 国土地理院「全国最新写真（シームレス）」 |
| 釣り場情報 | 一般に知られている情報にもとづく**参考値** |

⚠️ 潮汐は気象庁の潮汐表ではありません。渡船・磯釣りなど正確な潮位が必要な場面では、**必ず気象庁の潮汐表を確認してください**。

⚠️ 期待度は判断材料のひとつであり、**釣果を保証するものではありません**。釣行前には気象庁の警報・注意報と津波情報、現地の立入禁止表示を必ず確認してください。ライフジャケットの着用と、単独釣行を避けることを強くおすすめします。

## 環境変数

`.env.example` を `.env.local` にコピーして設定します。**すべて未設定でも、APIキーなしで実データを取得して動作します。**

| 変数 | 説明 |
|---|---|
| `NEXT_PUBLIC_WEATHER_API_URL` | 天気API。未設定時は `https://api.open-meteo.com/v1/forecast` |
| `NEXT_PUBLIC_MARINE_API_URL` | 波高API。未設定時は `https://marine-api.open-meteo.com/v1/marine` |
| `NEXT_PUBLIC_TIDE_API_URL` | 潮汐API（将来の実データ接続用）。未設定時はアプリ内計算 |
| `NEXT_PUBLIC_MAP_TILE_URL` | 地図タイルURL。未設定時は OpenStreetMap |
| `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase 接続情報。未設定時は端末内（localStorage）保存 |

APIキーはコードに直接書かず、必ず環境変数を使用してください。

## オフライン動作（PWA）

Service Worker が以下をキャッシュするため、電波の悪い現地でも操作できます。

- アプリの画面（ネットワーク優先 → 失敗時キャッシュ）
- 地図タイル（キャッシュ優先・最大400枚）
- 気象APIのレスポンス（ネットワーク優先 → 失敗時は前回値）

潮汐・日の出入り・まづめ・登録済み釣り場・過去の釣果は端末内で完結しているため、**完全オフラインでも表示できます**。

## Supabase の設定（任意）

1. [supabase.com](https://supabase.com) でプロジェクトを作成
2. SQL Editor で `supabase/schema.sql` を実行
3. Project Settings > API の URL と anon key を `.env.local` に設定
4. 写真をクラウド保存する場合は Storage に `photos` バケットを作成

現在は `lib/storage.ts` がデータアクセス層になっており、ここを差し替えれば Supabase 版になります。設定画面の「バックアップを保存/復元」で端末間のデータ移行ができます。
